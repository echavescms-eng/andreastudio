# Andréa Vargas Beauty

Site estático de apresentação, serviços, portfólio e solicitação de agendamento da Andréa Vargas. Feito em HTML, CSS e JavaScript, sem etapa de build.

## Abrir localmente

Abra `index.html` no navegador. Para testar como em um servidor, você também pode iniciar um servidor local simples a partir desta pasta, por exemplo com a extensão Live Server do VS Code.

## Publicar com GitHub Pages

1. Envie o conteúdo desta pasta para a raiz de um repositório GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch publicada (por exemplo, `main`) e a pasta **/(root)**; salve.
5. Aguarde a publicação e abra o endereço indicado na seção Pages.

O arquivo `index.html` é a página inicial. Mantenha `fundo.jpg`, os arquivos de logo e a pasta `portfolio/` junto dele para que as referências às imagens continuem funcionando.

## Agendamento

O formulário prepara uma mensagem para envio pelo WhatsApp. Ele não registra nem confirma automaticamente o horário; a equipe confirma a solicitação pelo WhatsApp.
